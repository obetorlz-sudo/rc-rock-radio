RC ROCK RADIO · PWA MÓVIL V3

Versión preparada para Android, iPhone/iPad y computador.

No usa archivo .BAT. Para funcionar como app instalable debe publicarse en un sitio HTTPS (por ejemplo Vercel o Netlify).

Incluye:
- PWA instalable
- Iconos Android 192/512 y maskable
- Apple Touch Icon
- Service Worker y modo standalone
- Navegación móvil con zona segura para iPhone
- Reproductor fijo
- Favoritos y recientes almacenados en el dispositivo
- Buscador, filtros, mapa, ranking y radio aleatoria
- Guía de instalación integrada para Android/iOS
- Priorización de streams HTTPS al ejecutarse publicada

Consulta README_MOVIL.txt para pasos rápidos.
