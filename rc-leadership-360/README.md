# RC Leadership 360

Aplicación de desarrollo organizacional para evaluación de supervisores con autoevaluación y percepción 360° del equipo.

## Estado

- Next.js desplegado en Vercel.
- PostgreSQL/Neon conectado.
- Esquema de base de datos inicializado automáticamente durante el build.
- Resultados 360° agregados solo con 3 o más respuestas.
- RUT de trabajadores transformado con HMAC para evitar almacenamiento en texto visible.

El instrumento es formativo y no corresponde al DISC o LPI oficial ni a un diagnóstico psicológico clínico.

Para una prueba visual del cuestionario, escribe `demo` como RUT en la portada.
